# Results

Results CSVs are generated by running the training and analysis scripts.
They are stored on the UND Talon HPC at:

  ~/results_v3/   — v3 baseline results
  ~/results_v4/   — v4 spatial holdout results

Key files:
  v4_results_all.csv              — full model comparison
  postprocess_v4_results.csv      — per-site breakdown
  scaling_results.csv             — GPU scaling experiment
  recoverability_results.csv      — recoverability curves
  training_loss_per_epoch.csv     — training history
  hyperparameter_config.csv       — all hyperparameters
  input_variables.csv             — all 26 input features
